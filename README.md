# Payment Reconciliation & Discrepancy Management Dashboard

## Project Overview

This project demonstrates a structured approach to payment reconciliation and discrepancy management using simulated payment and premium booking data.

The objective is to identify payment discrepancies, monitor outstanding issues, and support timely resolution through structured investigation, follow-up, and reporting.

**Important:** This is an independent portfolio project using fictional data. It does not contain confidential information from any previous employer.

## Business Problem

Payment records and premium booking records may not always match. Examples include:

- Payment amounts that differ from premium booking amounts.
- Payments received but not yet booked.
- Partial payments and outstanding balances.
- Transactions requiring investigation and follow-up.

Without structured monitoring, these discrepancies can affect record accuracy, reporting, and operational efficiency.

## Project Objectives

- Identify discrepancies between incoming payments and premium booking records.
- Classify discrepancies according to issue type.
- Monitor outstanding amounts and resolution status.
- Support structured investigation and follow-up.
- Improve visibility through operational reporting.

## Key Features

- Payment reconciliation

- Outstanding issue monitoring
- Investigation and follow-up tracking
- Operational dashboard and reporting

## Methodology

1. Prepare simulated payment and premium booking data.
2. Validate transaction identifiers and payment amounts.
3. Compare incoming payments with premium booking records.
4. Identify and classify discrepancies.
5. Record investigation status and follow-up actions.
6. Summarize results for operational monitoring.
